`pixel_persistence` 静态库接收普通 `WorldSnapshot` 与文件路径，显式编码小端字段和格式版本 12（读取并迁移版本 1～11，保留既有字段；版本 1～8 的脉冲补零所有者，1～9 的单元补零 Q24 液体流量余量，1～10 补零 Q16 动量补数，1～11 补零燃烧强度/烧损计数/焦化颜色/待点燃转换标记）；显式保存刚体局部像素/状态、姿态、速度、ID 与睡眠，保存活动燃烧的温度/寿命/燃料及已经锁定/延期的局部材料引信，保存当前/前一电能地址的刚体归属；校验长度、校验和、刚体连通形状及数量守恒。临时文件完成后替换目标；实际内容 ID 校验和世界替换由 `GameSession::restore_world` 完成。

首版同步读写并返回耗时，没有压缩、线程、通用迁移平台或断电恢复承诺。Godot 用户数据路径仅由 `godot_host` 转换后传入。格式与限制见项目 `docs/技术框架与性能.md`。
