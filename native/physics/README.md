`pixel_physics` 静态库实现 `RigidSolver`，使用锁定的 Box2D 3.1.1。它只保留派生碰撞形状、接触和求解缓存；实际像素、材料数量、ID 与公开运动状态由 `WorldState` 持有，并在同一固定步结束前回写。

固定地形按区块修订检查并按同材质合并矩形；刚体按实际局部像素建立可带孔洞的复合形状。没有 Godot 类型、逐像素 Node、后台线程或另外一份游戏材料状态。退出/重建/读档会重建物理缓存；当前耦合限制和保存保证集中维护在[技术框架与性能](../../docs/技术框架与性能.md)。

`LiquidSimulation` 在 Box2D 步之前用实际像素质量/惯量与湿接触面求解动态压力和双向隐式阻力，回写双方动量；本库随后按实际像素采样密度施加静水浮力并求解碰撞，不再重复施加单向阻力。液体与刚体共享 16 单元/米、10 米/秒² 和 60 Hz。静水重建仍为项目近似，原版独立浮力公式尚未还原；边界集中见技术文档。

接触摩擦读取实际材料的 `solid_friction`，材质变化也会使地形缓存失效。地形派生边界用于预求解时剔除被相邻固定实体覆盖的内部面，保留外露墙/台阶；回调仅在当前物理步借用只读世界查询。
