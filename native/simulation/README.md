`SourceLiquidSimulation` 在唯一固定步内处理原版风格的普通液体局部交换、下落与横向累计及概率密度交换；21 项预置启用新路径，不进入旧压力/远端导流。运动累计属于 WorldState，格式 15 保存。调度、额外下落选向和外力桥接仍是项目适配，刚体仅保留既有排液与浮力，不宣称完整原版受力。详细范围集中在技术文档。

`MaterialSimulation` 在会话固定步内处理分块材料的 Q8 加速/阻尼/稳定、密度交换、冲击、同材质松动/再固定、洞顶黏附/有限竖直挂滴、龄期/热量约束的两/三输入标签接触与区域反应、供氧/初始燃烧、宽整数燃料、配置家族相变/淬冷、冷热转换和寿命；仅使用普通 C++。实验场布置与调试命令也在此模块，场景坐标不进入固定步规则。数据与可修改状态归 Core，内容只读，变化由会话合并发布。具体范围见根技术文档。

`ExplosionSimulation` 在相同固定步中计算网格 DDA/旋转像素射线暴露、统一耐久/HP 遮挡、碎片压力/加热、引信和网格/刚体连通燃料聚合，并在容量检查后提交整次爆炸；不拥有第二份世界或引擎节点。参数与限制仍集中在技术文档。

`ElectricalSimulation` 处理有限电能注入、网格/刚体单点与批量地址转移和碎片清理；传播、分流、加热和余辉在 `MaterialInteractions` 中复用同一实际接触邻域。在途脉冲与显示由世界唯一拥有并可保存，路径变化不需要 UI 维护电路副本。

`RigidSimulation` 处理实际刚体像素的创建/地形转移、局部擦除、质量中心补偿和四邻分裂，通过已实现的 `RigidSolver` 边界提交一次固定步并回写姿态；运动后以稀疏单元计划沿通路逐格排开流动液体，保留各单元状态和原始地址，空间不足时保留材料并撤回候选运动。它只依赖标准库；Box2D 实现位于 `native/physics`。当前耦合边界与未实现部分集中见技术文档。

`MaterialInteractions` 共用网格与刚体的接触/区域反应和热/燃烧/寿命规则，规划产物释放和碎片容量后提交；形状变化在阶段末交给 `RigidSimulation` 重建，不复制整个材料世界。具体旋转接触近似、延后条件及尚未接通部分见技术文档。

`MaterialInteractions` 的源反应路径共用一次样本完成门槛/候选选择，区分普通、快速和缺失必要邻居入口；第三输入从第一位置的四邻居采样。标签全局绑定由 Content 注册表完成。`reaction_geometry.hpp` 只实现普通数据上的受限径向与无限制严格圆内几何；世界访问、C/B/A 局部计划和原子提交由交互阶段负责。作者旧模式继续使用原分母及连通圆规则。未新增持久状态或第二个更新入口，源调度频率与原版线程缓冲仍未还原。

`combustion.hpp` 提供源燃烧分支使用的 15 位 LCG、强度字节、强制点燃/直接熄灭和变色运算；传播、单一上方发焰、独立烟概率、发焰反馈、网格随机燃尽及刚体计数在 `MaterialInteractions` 提交。原版预置启用 `source_burning`；旧作者材料仍支持原燃料模式。两者共享唯一世界、固定步及产物容量检查，不新增调度器或 UI 状态。未知默认值、气体/火焰近似及存档兼容范围见技术文档。

液体近处直接探测与最多 16 项有限行缓存共用同一种可达规则；同种液体可传递通路方向，实际输运仍逐单元提交。行及下行的变化使缓存失效，远端出口唤醒同一区块行；缓存属于本步派生查询，不是另一份材料状态或存档数据。

`LiquidSimulation` 为未启用 source_liquid 的作者液体在同一固定步内处理连通液体的 MIC(0)/PCG 压力投影、Q16 动量、Q24 面流量、守量通路/环流、移动刚体动态压力与双向隐式阻力。压力和矩阵只在本步存在；状态继续归世界，存档格式 14 显式保存低速补数、流量余量及燃烧状态。共享物理单位在 `core/physical_units.hpp`，静止与边缘溢流判据、量化耗散和剩余近似见技术文档。

`source_phase.hpp` 承接源冷热门槛和气体构造计数，`source_blast.hpp` 承接只读方向探测，`source_adhesion.hpp` 承接坐标支撑方向和随机释放门槛；实际转换、附着/释放输运交接、持续 HP、气体移动递增、源电弧与分叉仍由现有阶段提交。新增状态、源／作者模式、未知调度与格式 14 定向兼容范围见技术文档，本模块不建立第二个世界或实体框架。
